# CSOS

Conqueror Studio Operating System. The source of truth for how the studio decides, designs, builds, reviews, and learns.

## Quick start

Read `docs/constitution.md`, then `docs/quality-gates.md`. For an implementation task, Hermes must read `.ai/system-prompt.md`, `.ai/implementation-rules.md`, and the relevant project PDS before changing code.

## Structure

- `.ai/` — portable AI instructions and review rules.
- `docs/` — governance, quality, decision records, and project requirements.
- `templates/` — project kick-off templates.

Version: `1.0.0`.

# Conqueror Studio Website — v1 Requirements

## Product intent

Present Conqueror Studio as a living, luxury digital atelier and convert qualified visitors to a free consultation.

## Required pages

Home; Work index; project detail; Journal; About; Contact; 404. Project and journal content must be publishable through a CMS or content workflow without editing page code.

## Visual direction

Ivory editorial canvas, ink-black type, restrained editorial blue accents, Renaissance-painting hero art, high-contrast serif display typography, modern sans-serif reading text, generous whitespace. Avoid SaaS gradients, generic AI imagery, heavy glass effects, fake social proof, and visual clutter.

## Core sections

Opening sequence (skippable and remembered), hero, manifesto, selected work, craft/services, latest updates, journal, archive, process, consultation CTA, editorial footer.

## Success measures

Consultation CTA works; content can be updated; mobile reading and interaction are excellent; all claims are truthful; metadata and basic analytics are configured before launch.

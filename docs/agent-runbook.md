# Hermes implementation runbook

Hermes is an implementation agent. Humans own direction, content truth, approval, and release decisions.

## Before editing
Read constitution, quality gates, project requirements, studio manifest, CDS handoff, project PDS, and project PRD in that order.

## During editing
- Work on a feature branch.
- Implement one vertical slice at a time.
- Reuse existing components and tokens.
- Never invent claims, content, or visual language.
- Stop when a material requirement is ambiguous.
- Do not modify main, secrets, or release metadata.

## Pull request evidence
Every agent PR includes summary, files changed, requirements satisfied, tests run, screenshots or preview URL, quality evidence, known risks, and human decisions required.
